Key Features:
Dual-Pane Interface:

Side-by-side file panels like the original Norton Commander
Active panel highlighting with colored borders
Tab key to switch between panels

File Operations:

F5: Copy files between panels
F6: Move files between panels
F7: Create new folders
F8: Delete files
F2: Refresh view
F10: Exit application
Enter: Enter directories or open files
Double-click: Navigate directories

Multiple Themes:

Classic DOS: Traditional blue/cyan Norton Commander look
Modern Dark: Contemporary dark theme
Light: Clean light theme
Matrix: Green-on-black hacker style

File Information:

File name, size, date modified, and attributes
Directory indicators
Parent directory navigation (..)
Proper file size formatting (B, KB, MB, GB)

Additional Features:

Menu bar with organized functions
Status bar showing current operations
Function key panel (F1-F10)
Keyboard shortcuts matching original Norton Commander
File attribute display (read, write, hidden, directory)
Confirmation dialogs for destructive operations
